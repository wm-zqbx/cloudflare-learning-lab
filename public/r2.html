Cloudflare 学习站第 9 课 · R2

附件变了，网页不必重发。

R2 是 Cloudflare 保存文件内容的服务。
先看它改善了哪一步，再看程序怎样使用它。

01 · 实际问题

客户不断补充需求附件。

项目网站已经上线，客户又交来一份 PDF。若每次都把附件放进网页源码再发布，开发者就得反复替换文件、发布网站。文件越多，这种维护越费力。

把附件放进 R2，网页代码只负责显示下载入口；程序按名字取得文件。附件变化与网页发布便可以分开。

什么时候不需要？固定的 logo、样式和几份随网站一起更新的文档，继续放在 Workers Static Assets 就足够。需要独立更新或接收用户文件时，再考虑 R2。

02 · 三个核心概念

内容、查找名、容器。

对象：保存的文件
可以理解为文件本体，加上大小、类型等说明。PDF、图片、文本都能存。
键：文件的查找名
例如 samples/brief.txt。程序拿这个名字取文件；斜杠只是命名习惯，不是真正的文件夹。
桶：容纳这些文件的地方
属于你的 Cloudflare 账号。同一账号的多个 Worker 可以连接同一个桶；它不会因某个网页项目删除而自动消失。

与前两课的分工：KV 适合按名字取公告、配置；D1 适合用表查询任务；R2 适合独立管理文件本体。完整项目可以让 D1 记“附件属于哪条任务、查找名是什么”，让 R2 保存 PDF。R2 本身不替你建立这条关联。

03 · 运行逻辑与分工

点击之后，谁做什么？

  1. 1 · 访客在网页点下载
  2. 2 · 你的 Worker确定文件的键
    向 R2 请求内容
  3. 3 · Cloudflare R2从云端桶取出文件
    返回实际内容
  4. 4 · 浏览器收到文件
    保存到自己的设备

本课文件留在 R2 的桶中，不在 Worker 的临时内存或网页代码里。浏览器得到一份副本，云端原件继续保留。

第一次与再次下载
本例每次都让 Worker 读取 R2，不保存网页缓存。下载不会消耗掉原件。
文件更新或删除
R2 确认替换后，直接读取会得到新内容；确认删除后，程序得到“文件不存在”。设备上已下载的副本仍在。另加缓存的项目需要处理旧副本；本例未加缓存。

开发者做一次：建桶，让 Worker 连接它，并编写读取及权限规则。桶默认不对外公开；本例的程序只提供一份公开样例。

程序每次做：收请求 → 确定文件 → 调用 R2 → 返回内容。无需运营为每次下载手工发文件。

用户或运营决定：上传什么、谁能下载、何时替换或删除。开发者可以写上传程序，让这些决定触发自动保存；R2 不会默认把网页选中的文件传到云端。

      需要动手时再看：开通、配置、代码与额度
      
账号开通页包含 R2 订阅、付款方式和超额使用计费条件，需要账号持有人自己确认。教学文件很小；免费额度仍不是无限容量和请求。

      
在自己的账号查看 R2 开通页 ↗

      
开通后创建项目专用桶并把它连接给 Worker。“绑定”就是让程序通过一个变量访问这个云端资源：

      
"r2_buckets": [{
  "binding": "FILES",
  "bucket_name": "cloudflare-learning-lab-files"
}]

      
一次性准备样例（在本仓库目录执行）：

      
npx wrangler r2 bucket create cloudflare-learning-lab-files
npx wrangler r2 object put cloudflare-learning-lab-files/samples/brief.txt --file docs/r2-sample.txt --content-type "text/plain; charset=utf-8" --remote

      
读取的核心逻辑如下，完整处理在仓库中：

      
const file = await env.FILES.get('samples/brief.txt');
if (!file) return new Response('文件不存在', { status: 404 });
return new Response(file.body);

      
未来上传由程序调用 FILES.put 保存；替换同一个键会覆盖该对象，删除由 FILES.delete 执行。也可以配置按期限清理的规则，但不会默认替你决定什么时候删。

      
R2 桶与 D1、KV 的资源都在账号下，项目配置决定连接哪一个。资源可以共用，但同一桶的读写会互相影响；连接桶并不等于自动拥有按客户隔离的权限。

      
本例接口返回 no-store，让下载通过 Worker 直接读 R2。R2 确认完成的更新与删除不会像 KV 那样等待跨地区旧值传播；但你另加的浏览器或分发缓存仍可能保留旧文件，需要单独处理。

      
Standard 每月免费包含约相当于持续存放 10 GB 的存储用量、100 万次写入等操作、1,000 万次读取等操作。直接从 R2 传出文件不收出网流量费；超出存储和操作额度会计费。其他服务可能另收费。
