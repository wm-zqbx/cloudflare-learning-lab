LIVE CACHE EXPERIMENT / 真实网络实验

同一份内容，在哪里被重复使用？

CDN 与缓存课 ↗
浏览器缓存
你的设备保留副本→Cloudflare 边缘缓存
多个访客复用公开内容→静态资源 / Worker
读取文件或处理请求

普通样式文件每次使用前校验新鲜度；带版本的公开文件允许浏览器缓存一年；实时接口使用 no-store。Workers Static Assets 自动处理边缘资源缓存，本实验无需新增 Cache Rule。

观察方式：绕过浏览器本地 HTTP 缓存，读取实际网络响应；请求地址保持相同，不添加随机参数。

响应结果：CF-Cache-Status 看边缘缓存，Cache-Control 看返回的缓存策略。
请求HTTPCF-Cache-StatusCache-Control内容与 ETag

HIT 表示头部报告命中；MISS 表示报告未命中，第二次也可能仍 MISS。头部未返回不等于请求失败；不能仅凭速度或 ETag 判断命中。Static Assets 官方说明该状态头存在少量误判可能。

发布新内容：查看 v1 ↗ → 查看 v2 ↗。新版本使用新 URL；长期缓存的 v1 不再原地修改。

公开图片、样式和版本文件适合缓存。账号资料、登录结果、订单状态需由应用选择 private / no-store。基础 DDoS 防护由平台提供；它不能替代登录、Turnstile 或接口限流。
