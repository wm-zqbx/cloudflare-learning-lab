本页公告已写入真实 KV。公开页面只读；修改使用你自己的 Cloudflare 管理权限。

在本项目目录运行下面命令，修改远端公告，再点“从 KV 重新读取”。修改传播可能需要等待，无需重新部署：

npx wrangler kv key put site-announcement "今晚 8 点学习 R2" --binding CONFIG --remote

Worker 的核心读取只有一句：

const announcement = await env.CONFIG.get('site-announcement');

CONFIG 是 Worker 连接的 KV 命名空间，可以理解为存放这组键值的容器。键不存在时，get 返回 null。

每次点击都会请求 Worker 并调用 KV 绑定；no-store 只阻止浏览器缓存接口，不会绕过 KV 自身的缓存和传播延迟。

Free 额度：1 GB 存储；每天读 10 万次，写、删除、列表操作各 1,000 次。超过免费额度，相应操作会失败。
